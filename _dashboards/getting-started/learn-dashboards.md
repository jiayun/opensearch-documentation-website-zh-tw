# 了解主要應用程式

OpenSearch Dashboards 提供數個應用程式，讓您處理資料。標準工作流程是先探索資料、建立個別視覺化，再將這些視覺化組合成儀表板。

## Discover 應用程式

**Discover** 應用程式可讓您以互動方式搜尋、篩選及檢視資料。您可以使用它來了解有哪些欄位可用、資料隨時間的分布情形，以及資料中存在哪些模式。

![Discover 應用程式顯示依延誤篩選的航班資料]({{site.url}}{{site.baseurl}}/images/dashboards/opensearch-dashboards-discover.png)

## Visualize 應用程式

**Visualize** 應用程式可讓您透過點選式介面，建立圖表、地圖、表格及其他資料的視覺化呈現。您可以選取視覺化類型、設定指標和桶 (bucket)，並調整顯示設定。

![在 Visualize 應用程式中建立的折線圖]({{site.url}}{{site.baseurl}}/images/dashboards/visualize-app-line-chart-example.png)

## Dashboards 應用程式

**Dashboards** 應用程式可讓您將多個視覺化組合在單一頁面中，以進行監控與分析。您可以新增現有的視覺化、建立新的視覺化、調整面板大小及位置，並套用會同時影響所有面板的篩選條件。

![包含多個視覺化面板的儀表板]({{site.url}}{{site.baseurl}}/images/dashboards/add-dash-panel.png)

## Dev Tools

**Dev Tools** 主控台可讓您使用 [Query DSL]({{site.url}}{{site.baseurl}}/query-dsl/) 直接執行 OpenSearch API 查詢。您可以使用它來測試查詢、管理索引及執行叢集作業，而不必離開瀏覽器。

![Dev Tools 主控台顯示查詢與回應]({{site.url}}{{site.baseurl}}/images/dev-tools/dev-tools-response.png)
