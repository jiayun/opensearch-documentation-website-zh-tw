# 設定地圖

您可以設定[座標地圖]({{site.url}}{{site.baseurl}}/dashboards/visualize/coordinate-maps/)和 [Maps 應用程式]({{site.url}}{{site.baseurl}}/dashboards/visualize/maps/)所使用的地圖圖磚伺服器。這些設定不適用於[區域地圖]({{site.url}}{{site.baseurl}}/dashboards/visualize/region-maps/)，因為區域地圖使用向量邊界（GeoJSON 檔案），而非點陣圖磚。

## 相關文件

- [設定 Web Map Service (WMS)]({{site.url}}{{site.baseurl}}/dashboards/visualize/maptiles/) -- 設定 WMS 圖磚伺服器以使用自訂底圖。
- [使用自行託管的地圖伺服器]({{site.url}}{{site.baseurl}}/dashboards/visualize/selfhost-maps-server/) -- 在本機託管地圖圖磚，以用於實體隔離 (air-gapped) 環境。
