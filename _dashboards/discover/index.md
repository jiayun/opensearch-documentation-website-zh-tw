# 探索資料

OpenSearch Dashboards 提供了多種探索資料的工具，支援從基礎的一次性查詢到可儲存且等同於 API 的查詢。您可以執行以下操作：

- 在 **Discover** 或 **Dashboards** 搜尋列中使用 Dashboards 查詢語言 (DQL)（一種用於基礎查詢的 Dashboards 專用語言）或基於 Apache Lucene 的查詢字串查詢語言 (Query String Query Language) 來探索資料。
- 使用 **Query Workbench** 工具以 SQL 或管線處理語言 (Piped Processing Language, PPL) 執行查詢。
- 使用 **Dev Tools** 主控台以查詢領域特定語言 (Query DSL) 執行查詢。透過 Query DSL，您可以像從 API 執行一樣執行任何查詢。
- 在 **Discover** 和 **Visualize** 工具中顯示並儲存查詢資料的視覺化圖表。
