# 詞元篩選器

詞元篩選器會接收來自斷詞器的詞元串流，並新增、移除或修改詞元。例如，詞元篩選器可以將詞元轉換為小寫，讓 `Actions` 變成 `action`；移除 `than` 等停用詞；或為單字 `speak` 新增 `talk` 等同義詞。

下表列出 OpenSearch 支援的所有詞元篩選器。
