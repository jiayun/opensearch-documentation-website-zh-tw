# Amazon S3 記錄檔類型

`s3` 記錄檔類型會追蹤存取 Amazon S3 儲存貯體的網路請求。

下列程式碼片段包含此記錄檔類型的所有 `raw_field` 與 `ecs` 對應：

```json
  "mappings": [
    {
      "raw_field":"eventName",
      "ecs":"aws.cloudtrail.event_name"
    },
    {
      "raw_field":"eventSource",
      "ecs":"aws.cloudtrail.event_source"
    },
    {
      "raw_field":"eventTime",
      "ecs":"timestamp"
    }
  ]
```
