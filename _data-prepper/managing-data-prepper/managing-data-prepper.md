# 管理 OpenSearch Data Prepper

您可以執行 OpenSearch Data Prepper 的管理員功能，包括系統組態、與核心 API 互動、Log4j 組態和監控。使用具狀態彙總時，您可以設定對等轉送，以協調多個 Data Prepper 節點。
