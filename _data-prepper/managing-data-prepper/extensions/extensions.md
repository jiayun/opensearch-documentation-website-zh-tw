# Data Prepper 擴充功能

OpenSearch Data Prepper 擴充功能提供 Data Prepper 核心管線元件以外的功能。
許多擴充功能提供組態選項，讓 Data Prepper 管理員對 Data Prepper 的功能擁有更大的彈性。

擴充功能組態可以在 `data-prepper-config.yaml` 檔案的 `extensions:` YAML 區塊中設定。
