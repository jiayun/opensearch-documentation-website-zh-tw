# OTel APM 服務地圖處理器

`otel_apm_service_map` 處理器會分析 OpenTelemetry (OTel) 追蹤 span，自動產生應用程式效能監控 (APM) 服務地圖的關聯性與指標。它會建立結構化事件，可視覺化為服務拓撲圖，顯示服務之間如何互相通訊，並詳細說明其效能特性。

`otel_apm_service_map` 處理器提供現有 [`service_map` 處理器]({{site.url}}{{site.baseurl}}/data-prepper/pipelines/configuration/processors/service-map/) 的所有功能，同時提供增強的可觀測性能力。除了產生服務地圖之外，它還會建立以時間為基礎的服務地圖，擷取服務之間的關聯性如何隨時間演變，而非產生靜態的呈現方式。

此處理器也會自動為每個服務產生 Rate、Errors 與 Duration (RED) 指標，無需額外組態即可立即掌握服務的健康狀態與效能。

Option | Required | Type | Description
:--- | :--- | :--- | :---
`window_duration` | No | Duration | 評估 APM 服務地圖關聯性的固定時間視窗。支援 ISO-8601 時長格式 (例如 `PT60S` 或 `PT1M`) 或簡單的整數值 (解讀為秒)。預設值為 `60s`。
`db_path` | No | String | 用於建立資料庫檔案的目錄路徑，在處理 APM 服務地圖資料時儲存暫時性的堆積記憶體資料。預設值為 `data/otel-apm-service-map/`。
`group_by_attributes` | No | List | 當 OTel 資源屬性名稱存在於 span 的資源屬性中時，要複製到 `Service.groupByAttributes` 的名稱清單。此設定僅適用於主要 `Service` 物件，不適用於相依服務。預設為空清單。

## 用法

```yaml
entry-pipeline:
   source:
     otel_trace_source:
       path: "/test/path"
   sink:
     - pipeline:
         name: "raw-pipeline"
     - pipeline:
         name: "service-map-pipeline"
raw-pipeline:
   source:
     pipeline:
       name: "entry-pipeline"
   processor:
     - otel_trace_raw:
   sink:
     - opensearch:
         hosts: [<host>]
         index_type: trace-analytics-raw
service-map-pipeline:
   source:
     pipeline:
       name: "entry-pipeline"
   processor:
     - otel_apm_service_map:
         window_duration: 60s
         db_path: "data/otel-apm-service-map/"
   sink:
     - opensearch:
         hosts: [<host>]
         index_type: trace-analytics-service-map
```

## 指標

下表說明常見的 [Abstract processor](https://github.com/opensearch-project/data-prepper/blob/main/data-prepper-api/src/main/java/org/opensearch/dataprepper/model/processor/AbstractProcessor.java) 指標。

| Metric name | Type | Description |
| ------------- | ---- | -----------|
| `recordsIn` | Counter | 記錄進入管線元件的輸入量。 |
| `recordsOut` | Counter | 記錄離開管線元件的輸出量。 |
| `timeElapsed` | Timer | 管線元件執行期間所經過的時間，單位為毫秒。 |

`otel_apm_service_map` 處理器包含下列自訂指標。

| Metric name | Type | Description |
| ------------- | ---- | -----------|
| `spansDbSize` | Gauge | 所有三個 span 資料庫視窗的總大小，單位為位元組。 |
| `spansDbCount` | Gauge | 所有三個 span 資料庫視窗中的 span 項目總數。 |
