# OTel metrics 處理器

`otel_metrics` 處理器會將從 [OTel metrics source]({{site.url}}{{site.baseurl}}/data-prepper/pipelines/configuration/sources/otel-metrics-source/) 傳送來的 `ExportMetricsServiceRequest` 記錄集合序列化為字串記錄集合。

## 使用方式

若要開始使用，請將下列處理器新增至您的 `pipeline.yaml` 組態檔：

``` yaml
processor:
    - otel_metrics:
```
{% include copy.html %}

## 組態

您可以使用下列選用參數來設定長條圖的桶及其預設值。長條圖會將資料分組為桶，以顯示數值資料。您可以使用長條圖桶來檢視依事件總數及所有事件的彙總總和所組織的事件集合。如需更詳細的資訊，請參閱 [OpenTelemetry Histograms](https://opentelemetry.io/docs/reference/specification/metrics/data-model/#histogram)。

### calculate_histogram_buckets
<!-- vale on -->

如果 `calculate_histogram_buckets` 未設定為 `false`，則下列 `JSON` 檔案會新增至每個長條圖 JSON。如果 `flatten_attributes` 設定為 `false`，指標的 `JSON` 字串格式不會變更 attributes 欄位。如果 `flatten_attributes` 設定為 `true`，attributes 欄位中的值會放置在上層的 `JSON` 物件中。預設值為 `true`。請參閱下列 `JSON` 範例：

```json
 "buckets": [
    {
      "min": 0.0,
      "max": 5.0,
      "count": 2
    },
    {
      "min": 5.0,
      "max": 10.0,
      "count": 5
    }
  ]
```

您可以建立長條圖桶及其邊界的詳細表示。您可以在 `pipeline.yaml` 檔案中使用下列參數來控制此功能：

```yaml
  processor:
    - otel_metrics_raw_processor:
        calculate_histogram_buckets: true
        calculate_exponential_histogram_buckets: true
        exponential_histogram_max_allowed_scale: 10
        flatten_attributes: false
```
{% include copy.html %}

每個陣列元素描述一個桶。每個桶包含下邊界、上邊界及其值計數。這是更詳細的 OpenTelemetry 表示形式的特定樣式，屬於 `otel_metrics` 處理器所建立 `JSON` 輸出的一部分。請參閱下列 `JSON` 檔案，該檔案由 `otel_metrics` 處理器新增至每個 `JSON` 長條圖：

```json
 "explicitBounds": [
    5.0,
    10.0
  ],
   "bucketCountsList": [
    2,
    5
  ]
```

### calculate_exponential_histogram_buckets
<!-- vale on -->

如果 `calculate_exponential_histogram_buckets` 設定為 `true` (預設設定)，則下列 `JSON` 值會新增至每個 `JSON` 長條圖：

```json

    "negativeBuckets": [
        {
        "min": 0.0,
        "max": 5.0,
        "count": 2
        },
        {
        "min": 5.0,
        "max": 10.0,
        "count": 5
        }
    ],
...
    "positiveBuckets": [
        {
        "min": 0.0,
        "max": 5.0,
        "count": 2
        },
        {
        "min": 5.0,
        "max": 10.0,
        "count": 5
        }
    ],
```

下列 `JSON` 檔案是更詳細的 OpenTelemetry 表示形式，由負桶與正桶、scale 參數、offset 以及桶計數清單組成： 


```json
    "negative": [
        1,
        2,
        3
    ],
    "positive": [
        1,
        2,
        3
    ],
    "scale" : -3,
    "negativeOffset" : 0,
    "positiveOffset" : 1
```

### exponential_histogram_max_allowed_scale
<!-- vale on -->

`exponential_histogram_max_allowed_scale` 參數定義指數長條圖所允許的最大刻度。如果您增加此參數，將會增加潛在的記憶體消耗。如需指數長條圖及其計算複雜度的詳細資訊，請參閱 [OpenTelemetry specifications](https://github.com/open-telemetry/opentelemetry-proto/blob/main/opentelemetry/proto/metrics/v1/metrics.proto)。

所有刻度高於所設定參數 (預設值為 `10`) 的指數長條圖都會被捨棄，並以錯誤層級記錄。您可以檢查 OpenSearch Data Prepper 所建立的記錄檔，以查看 `ERROR` 記錄訊息。

比較時使用刻度的絕對值，因此 `-11` 的刻度會被視為等同於 `11`，超過所設定的 `10` 值，因此可能會被捨棄。
{: .note}

## 指標

下表說明所有處理器共通的指標。

| 指標名稱 | 類型 | 說明 |
| ------------- | ---- | -----------|
| `recordsIn` | Counter | 代表流入記錄數量的指標。 |
| `recordsOut` | Counter | 代表流出記錄數量的指標。 |
| `timeElapsed` | Timer | 代表記錄執行期間所經過時間的指標。 |
