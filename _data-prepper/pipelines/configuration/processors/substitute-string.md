# 字串取代處理器

`substitute_string` 處理器會以規則運算式比對鍵的值，並將所有符合的結果替換為指定的取代字串。

## 組態

下表說明設定 `substitute_string` 處理器時可使用的選項。

選項 | 必要 | 類型 | 說明
:--- | :--- | :--- | :---
`entries` | 是 | List | 項目清單。有效值為 `source`、`from` 和 `to`。
`source` | N/A | N/A | 要修改的鍵。
`from` | N/A | N/A | 要被取代的規則運算式字串。使用雙引號時，`[` 和 `]` 等特殊規則運算式字元必須以 `\\` 逸出；使用單引號時則以 `\ ` 逸出。如需更多資訊，請參閱 [Java Patterns](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/regex/Pattern.html)。
`to` | N/A | N/A | 用來取代每個 `from` 符合結果的字串。


### 使用方式

首先，建立下列 `pipeline.yaml` 檔案：

```yaml
pipeline:
  source:
    file:
      path: "/full/path/to/logs_json.log"
      record_type: "event"
      format: "json"
  processor:
    - substitute_string:
        entries:
          - source: "message"
            from: ":"
            to: "-"
  sink:
    - stdout:
```
{% include copy.html %}

接著，建立名為 `logs_json.log` 的記錄檔。然後，將 `pipeline.yaml` 檔案中檔案來源的 `path` 替換為您的檔案路徑。如需更詳細的資訊，請參閱[執行 Data Prepper]({{site.url}}{{site.baseurl}}/data-prepper/getting-started/running/)。

執行 Data Prepper 之前，來源會以下列格式呈現：

```json
{"message": "ab:cd:ab:cd"}
```

執行 Data Prepper 之後，來源會轉換為下列格式：

```json
{"message": "ab-cd-ab-cd"}
```

`from` 定義要替換的字串，`to` 則定義用來取代 `from` 字串的字串。在上述範例中，字串 `ab:cd:ab:cd` 會變成 `ab-cd-ab-cd`。如果 `from` 規則運算式字串未傳回相符結果，則會傳回該鍵，且不做任何變更。
