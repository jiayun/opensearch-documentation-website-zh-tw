# Obfuscate 處理器

`obfuscate` 處理程序可讓您將文件內的欄位進行混淆，以保護敏感性資料。

## 使用方式

在下列範例中，文件包含一個 `log` 欄位和一個 `phone` 欄位，如下列物件所示：

```json
{
  "id": 1,
  "phone": "(555) 555 5555",
  "log": "My name is Bob and my email address is abc@example.com"
}
```


若要混淆 `log` 和 `phone` 欄位，請新增 `obfuscate` 處理器，並在 `source` 選項中呼叫每個欄位。為了同時處理 `log` 和 `phone` 欄位，下列範例使用多個 `obfuscate` 處理器，因為每個處理器只能混淆一個來源。

在管線中的第一個 `obfuscate` 處理器中，來源 `log` 使用數個組態選項來遮罩 log 欄位中的資料，如下列範例所示。如需這些選項的詳細資訊，請參閱[組態](#configuration)。

```yaml
pipeline:
  source:
    http:
  processor:
    - obfuscate:
        source: "log"
        target: "new_log"
        patterns:
          - "[A-Za-z0-9+_.-]+@([\\w-]+\\.)+[\\w-]{2,4}"
        action:
          mask:
            mask_character: "#"
            mask_character_length: 6
    - obfuscate:
        source: "phone"
  sink:
    - stdout:
```

執行時，`obfuscate` 處理器會將欄位解析成下列輸出：

```json
{
  "id": 1,
  "phone": "***",
  "log": "My name is Bob and my email address is abc@example.com",
  "newLog": "My name is Bob and my email address is ######"
}
```

請搭配 `obfuscate` 處理器使用下列組態選項。

| 參數 | 必要 | 說明 |
| :--- | :---  | :---  |
| `source` | 是 | 要混淆的來源欄位。 |
| `target` | 否 | 用來儲存混淆後值的新欄位。這會讓原始來源欄位保持不變。未提供 `target` 時，來源欄位會以混淆後的值更新。 |
| `patterns` | 否 | 一組 regex 模式清單，可讓您混淆欄位的特定部分。只有符合 regex 模式的部分才會被混淆。未提供時，處理器會混淆整個欄位。 |
| `single_word_only` | 否 | 設為 `true` 時，會將字詞邊界 `\b` 新增至模式，這會讓混淆只套用至輸入文字中獨立的字詞。預設為 `false`，表示混淆模式會套用至所有出現處。可用於 Data Prepper 2.8 或更新版本。
| `obfuscate_when` | 否 | 指定 Obfuscate 處理器應在何種條件下執行比對。預設為無條件。 |
| `tags_on_match_failure` | 否 | 當 obfuscate 處理器無法比對模式時，要新增至事件中的標籤。 |
| `action` | 否 | 混淆動作。自 Data Prepper 2.3 起，僅支援 `mask` 動作。 |

您可以使用下列選用組態選項來自訂 `mask` 動作。

| 參數 | 預設 | 說明 |
| :--- | :---  | :---  |
`mask_character` | `*` | 遮罩時使用的字元。有效字元為 !、#、$、%、&、* 和 @。 |
`mask_character_length` | `3` | 欄位中要遮罩的字元數。值必須介於 1 到 10 之間。 |


## 預先定義的模式

使用 `patterns` 組態選項時，您可以針對常見欄位使用一組預先定義的混淆模式。`obfuscate` 處理器支援下列預先定義的模式。

您無法為一個 obfuscate 處理器使用多個模式。請為每個 obfuscate 處理器使用一個模式。
{: .note}


| 模式名稱          | 範例                                                                                                                                                                      |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `%{EMAIL_ADDRESS}`      | `abc@test.com`<br/>`123@test.com`<br/>`abc123@test.com`<br/>`abc_123@test.com`<br/>`a-b@test.com`<br/>`a.b@test.com`<br/>`abc@test-test.com`<br/>`abc@test.com.cn`<br/>`abc@test.mail.com.org` |
| `%{IP_ADDRESS_V4}`      | `1.1.1.1`<br/>`192.168.1.1`<br/>`255.255.255.0`                                                                                                                                     |
| `%{BASE_NUMBER}`        | `1.1`<br/>`.1`<br/>`2000`                                                                                                                                                           |
| `%{CREDIT_CARD_NUMBER}` | `5555555555554444`<br/>`4111111111111111`<br/>`1234567890123456`<br/>`1234 5678 9012 3456`<br/>`1234-5678-9012-3456`                                                                   |
| `%{US_PHONE_NUMBER}`    | `1555 555 5555`<br/>`5555555555`<br/>`1-555-555-5555`<br/>`1-(555)-555-5555`<br/>`1(555) 555 5555`<br/>`(555) 555 5555`<br/>`+1-555-555-5555`                                          |
| `%{US_SSN_NUMBER}`      | `123-11-1234`
