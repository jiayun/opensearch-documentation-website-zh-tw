# OTel trace 處理器

`otel_trace` 處理器會為所有傳入的 OpenSearch Data Prepper span 記錄補齊與追蹤群組相關的欄位，作法是為每個 `traceId` 以狀態快取根 span 資訊。

## 使用方式

此處理器會將下列欄位新增至 span 事件：

* `traceGroup`：根 span 名稱
* `endTime`：整個追蹤的結束時間，採用國際標準化組織 (ISO) 8601 格式
* `durationInNanos`：整個追蹤的持續時間，以奈秒為單位
* `statusCode`：整個追蹤的狀態碼，以奈秒為單位

`otel_trace` 處理器包含下列自訂指標：

* `traceGroupCacheCount`：追蹤群組快取中的追蹤群組數目。
* `spanSetCount`：span 集合中的 span 集數目。
