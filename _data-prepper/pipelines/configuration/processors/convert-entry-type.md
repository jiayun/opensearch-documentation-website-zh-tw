# 轉換類型處理器

`convert_type` 處理器會將事件中指定索引鍵所對應的值類型轉換為指定類型。這是一種型別轉換處理器，可變更事件中部分欄位的類型。有些資料必須轉換為不同類型，例如將整數轉換為雙精度浮點數，或將字串轉換為整數，才能讓事件通過以條件為基礎的處理器，或執行條件式路由。

從 OpenSearch Data Prepper 2.10.0 版開始，`convert_entry_type` 處理器已重新命名為 `convert_type`。使用 `convert_entry_type` 的組態會產生已淘汰警告，應予以更新。
{: .important }

| 選項 | 必要 | 說明 |
| :--- | :--- | :--- |
| `key`| 是 | 值需要轉換為不同類型的索引鍵。 |
| `keys`| 是 | 值需要轉換為不同類型的多個索引鍵。 |
| `type` | 否 | 索引鍵值配對的目標類型。可能的值為 `integer`、`long`、`double`、`big_decimal`、`string` 和 `boolean`。預設值為 `integer`。 |
| `null_values` | 否 | 用來表示哪些內容構成 `null` 值的字串。如果欄位值等於其中一個字串，則該值會被視為 `null`，並轉換為 `null`。 |
| `scale` | 否 | 轉換為 `big_decimal` 時，修改 `big_decimal` 的小數位數。預設值為 `0`。 |
| `tags_on_failure` | 否 | 事件轉換失敗時，要新增至事件中繼資料的標籤清單。 |
| `convert_when` | 否 | 使用 [Data Prepper 運算式]({{site.url}}{{site.baseurl}}/data-prepper/pipelines/expression-syntax/) 指定執行 `convert_type` 作業的條件。如果指定此選項，只有在運算式求值結果為 `true` 時，才會執行 `convert_type` 作業。 |

## 使用方式

首先，建立下列 `pipeline.yaml` 檔案：

```yaml
type-conv-pipeline:
  source:
    ...
  ....  
  processor:
    - convert_type:
        key: "response_status"
        type: "integer"
```
{% include copy.html %}

接著，建立名為 `logs_json.log` 的記錄檔，並將您 `pipeline.yaml` 檔案中檔案來源的 `path` 替換為該檔案路徑。如需更多資訊，請參閱 [設定 OpenSearch Data Prepper]({{site.url}}{{site.baseurl}}/data-prepper/getting-started/#2-configuring-data-prepper)。 

例如，在您執行 `convert_type` 處理器之前，如果 `logs_json.log` 檔案包含下列事件記錄：


```json
{"message": "value", "response_status":"200"}
```

`convert_type` 處理器會將收到的輸出轉換為下列輸出，其中 `response_status` 值的類型會從字串變更為整數：

```json
{"message":"value","response_status":200}
```
