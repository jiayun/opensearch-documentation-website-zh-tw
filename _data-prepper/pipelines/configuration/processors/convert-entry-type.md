# 轉換類型處理器

`convert_type` 處理器會將事件中指定索引鍵所對應的值類型轉換為指定類型。這是一種型別轉換處理器，可變更事件中部分欄位的類型。有些資料必須轉換為不同類型，例如將整數轉換為雙精度浮點數，或將字串轉換為整數，才能讓事件通過以條件為基礎的處理器，或執行條件式路由。

從 OpenSearch Data Prepper 2.10.0 版開始，`convert_entry_type` 處理器已重新命名為 `convert_type`。使用 `convert_entry_type` 的組態會產生已淘汰警告，應予以更新。
{: .important }

| 選項 | 必要 | 說明 |
| :--- | :--- | :--- |
| `key`| 視情況而定 | 要轉換為其他類型之值的鍵。除非已指定 `keys` 或 `coerce_strings`，否則為必要。不可與 `keys` 一起使用。 |
| `keys`| 視情況而定 | 要轉換為其他類型之值的多個鍵。除非已指定 `key` 或 `coerce_strings`，否則為必要。不可與 `key` 一起使用。 |
| `type` | 否 | 鍵值組的目標類型。可能的值為 `integer`、`long`、`double`、`big_decimal`、`string` 和 `boolean`。預設值為 `integer`。 |
| `null_conversion_values` | 否 | 代表 `null` 值的字串清單。如果 `key` 或 `keys` 中指定之欄位的值等於其中一個字串，該欄位就會從事件中移除。 |
| `iterate_on` | 否 | 事件中物件清單的鍵。指定此選項時，處理器會轉換清單中每個物件的 `key` 或 `keys` 欄位。 |
| `coerce_strings` | 否 | 指定此選項時，處理器會將事件中所有欄位（包括巢狀物件和清單中的欄位）的字串值，轉換為該字串所代表的類型。字串 `true` 和 `false`（不區分大小寫）會轉換為布林值。包含冒號（`:`）且符合其中一個 `coerce_strings.time_formats` 模式的字串，會轉換為 epoch 毫秒。包含小數點或指數的數值字串會轉換為 double，其他數值字串則會轉換為整數；如果超出整數範圍，則會轉換為 long。無法轉換的字串不會變更。將 `coerce_strings` 指定為空物件（`{}`）即可使用預設時間格式。 |
| `coerce_strings.time_formats` | 否 | 用於將時間字串轉換為 epoch 毫秒的 [Java DateTimeFormatter](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/time/format/DateTimeFormatter.html) 模式清單。未包含時區偏移的時間字串會以系統時區解譯，而未包含年份的模式則會使用目前年份。預設為 `["MMM d HH:mm:ss", "yyyy-MM-dd'T'HH:mm:ss.SSSXXX", "yyyy-MM-dd'T'HH:mm:ss.SSSSSSX", "dd/MMM/yyyy:HH:mm:ss Z"]`。 |
| `scale` | 否 | 轉換為 `big_decimal` 時，修改 `big_decimal` 的小數位數（scale）。預設值為 `0`。 |
| `tags_on_failure` | 否 | 事件轉換失敗時，要新增至事件中繼資料的標籤清單。 |
| `convert_when` | 否 | 使用 [Data Prepper 運算式]({{site.url}}{{site.baseurl}}/data-prepper/pipelines/expression-syntax/) 指定執行 `convert_type` 操作的條件。如果已指定，只有在運算式評估結果為 `true` 時，才會執行 `convert_type` 操作。 |

## 使用方式

若要開始使用，請建立下列 `pipeline.yaml` 檔案：

```yaml
type-conv-pipeline:
  source:
    ...
  ....  
  processor:
    - convert_type:
        key: "response_status"
        type: "integer"
```
{% include copy.html %}

接著，建立名為 `logs_json.log` 的記錄檔，並將 `pipeline.yaml` 檔案來源中的 `path` 取代為該檔案路徑。如需詳細資訊，請參閱[執行 Data Prepper]({{site.url}}{{site.baseurl}}/data-prepper/getting-started/running/)。

例如，在您執行 `convert_type` 處理器之前，如果 `logs_json.log` 檔案包含下列事件記錄：


```json
{"message": "value", "response_status":"200"}
```

`convert_type` 處理器會將收到的輸出轉換為下列輸出，其中 `response_status` 值的類型會從字串變成整數：

```json
{"message":"value","response_status":200}
```
