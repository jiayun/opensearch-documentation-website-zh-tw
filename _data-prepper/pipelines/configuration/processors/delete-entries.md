# Delete entries 處理器

`delete_entries` 處理器會從事件中移除項目，例如鍵值對。使用 `with_keys` 欄位指定要刪除的確切鍵。若要刪除符合正規表示式模式的鍵，請使用 `with_keys_regex` 欄位。您可以在使用正規表示式時，透過設定 `exclude_from_regex` 欄位來防止特定事件被刪除。

在同一個 `delete_entries` 處理器中同時設定 `with_keys` 與 `with_keys_regex` 的唯一方式，是使用 `entries` 欄位。

## 組態

## 用法
若要開始使用，請建立下列 `pipeline.yaml` 檔案：

```yaml
pipeline:
  source:
    ...
  ....
  processor:
    - delete_entries:
        with_keys: [ "message" ]
  sink:
```
{% include copy.html %}

接著，建立名為 `logs_json.log` 的記錄檔，並將 `pipeline.yaml` 檔案中 file source 的 `path` 替換為該檔案路徑。如需更多資訊，請參閱 [Configuring OpenSearch Data Prepper]({{site.url}}{{site.baseurl}}/data-prepper/getting-started/#2-configuring-data-prepper)。

例如，在執行 `delete_entries` 處理器之前，如果 `logs_json.log` 檔案包含下列事件記錄：

```json
{"message": "hello", "message2": "goodbye"}
```

當您執行 `delete_entries` 處理器時，它會將訊息剖析為下列輸出：

```json
{"message2": "goodbye"}
```


### 刪除符合模式的鍵

首先，建立下列 `pipeline.yaml` 檔案：

```yaml
pipeline:
  source:
    ...
  ....
  processor:
    - delete_entries:
        with_keys_regex: [ "^tes.*" ]
        exclude_from_delete: [ "test" ]
  sink:
```
{% include copy.html %}

如果您的 `logs_json.log` 檔案包含下列事件記錄：

```json
{"test": "friends", "test2": "are", "test3": "kind"}
```

當您執行 `delete_entries` 處理器時，它會將訊息剖析為下列輸出：

```json
{"test": "friends"}
```

### 合併多個刪除規則

首先，建立下列 `pipeline.yaml` 檔案：

```yaml
pipeline:
  source:
    ...
  ....
  processor:
    - delete_entries:
        entries:
          - with_keys: [ "message" ]
          - with_keys_regex: [ "^tes.*" ]
            exclude_from_delete: [ "test" ]
  sink:
```
{% include copy.html %}

如果您的 `logs_json.log` 檔案包含下列事件記錄：

```json
{"message": "hello", "message2": "goodbye", "test": "friends", "test2": "are", "test3": "kind"}
```

當您執行 `delete_entries` 處理器時，它會將訊息剖析為下列輸出：

```json
{"message2": "goodbye","test": "friends"}
```

> 如果 `with_keys`、`with_keys_regex` 或 `exclude_from_delete` 值未符合任何事件鍵，則不會執行任何動作。
