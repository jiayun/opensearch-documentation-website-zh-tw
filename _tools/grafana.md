# Grafana 支援

Grafana 有一個資料來源外掛程式，可讓您探索及視覺化您的 OpenSearch 資料。如需開始使用此外掛程式的相關資訊，請參閱 [Grafana 概觀頁面](https://grafana.com/grafana/plugins/grafana-opensearch-datasource/)。
