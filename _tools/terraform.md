# Terraform 提供者

您可以使用 Terraform OpenSearch 提供者來佈建 OpenSearch 資源，並與 OpenSearch API 互動。Terraform 提供者支援 Amazon OpenSearch Service 網域，以及部署在 Kubernetes 或其他基礎架構上的 OpenSearch 叢集。如需更多資訊，請參閱 [Terraform 提供者說明文件](https://registry.terraform.io/providers/opensearch-project/opensearch/latest/docs)。
