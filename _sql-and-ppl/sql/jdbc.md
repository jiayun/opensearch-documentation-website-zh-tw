# JDBC 驅動程式

Java Database Connectivity (JDBC) 驅動程式可讓您將 OpenSearch 與您喜愛的商業智慧 (BI) 應用程式整合。

關於下載及使用 JAR 檔案的資訊，請參閱 [GitHub 上的 SQL 儲存庫](https://github.com/opensearch-project/sql-jdbc)。

## 連線至 Tableau

若要連線至 Tableau，請依照 [GitHub 儲存庫](https://github.com/opensearch-project/sql-jdbc/blob/main/bi-connectors/TableauConnector/README.md)中的詳細指示操作。
