# 稽核記錄 API

稽核記錄 API 可擷取及修改稽核記錄組態。

OpenSearch 支援下列稽核記錄 API。

| API | 說明 |
| :--- | :--- |
| [Update Audit Configuration API]({{site.url}}{{site.baseurl}}/security/api/audit/update-audit-configuration/) | 開啟或關閉稽核記錄，並取代稽核記錄與合規組態。 |
| [Patch Audit Configuration API]({{site.url}}{{site.baseurl}}/security/api/audit/patch-audit-configuration/) | 更新稽核記錄與合規組態中的個別欄位。 |
| [Get Audit Configuration API]({{site.url}}{{site.baseurl}}/security/api/audit/get-audit-configuration/) | 擷取稽核記錄與合規組態。 |
