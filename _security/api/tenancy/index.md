# 多租用戶組態 API

多租用戶組態 API 可為 OpenSearch Dashboards 設定多租用戶，並傳回目前使用者可使用之租用戶的相關資訊。

OpenSearch 支援下列多租用戶組態 API。

| API | 說明 |
| :--- | :--- |
| [建立或更新多租用戶組態 API]({{site.url}}{{site.baseurl}}/security/api/tenancy/update-tenancy-config/) | 建立或取代多租用戶組態。 |
| [取得多租用戶組態 API]({{site.url}}{{site.baseurl}}/security/api/tenancy/get-tenancy-config/) | 擷取多租用戶組態。 |
| [租用戶資訊 API]({{site.url}}{{site.baseurl}}/security/api/tenancy/tenant-info/) | 傳回做為目前租用戶後端的索引名稱。 |
