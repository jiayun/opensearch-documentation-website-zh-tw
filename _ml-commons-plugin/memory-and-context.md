# 記憶與脈絡

OpenSearch 提供智慧型記憶與脈絡管理系統，讓 AI 代理程式能夠跨工作階段維持持久的知識與對話脈絡。

## 記憶系統

OpenSearch 提供兩種互補的記憶方式：

- **[代理記憶（Agentic memory）]({{site.url}}{{site.baseurl}}/ml-commons-plugin/agentic-memory/)**：一種智慧型記憶系統，使用大型語言模型（LLM）擷取洞見、學習使用者偏好，並在代理程式互動之間維持脈絡知識。

- **[脈絡管理]({{site.url}}{{site.baseurl}}/ml-commons-plugin/context-management/)**：一種結構化方法，用於管理 AI 代理程式與應用程式的對話脈絡和系統狀態。

## 相關 API

若要透過程式存取記憶與脈絡功能，請參閱：

- **[代理記憶 API]({{site.url}}{{site.baseurl}}/ml-commons-plugin/api/agentic-memory-apis/)**：管理記憶容器、工作階段與記憶的完整 API 參考文件。
- **[脈絡管理 API]({{site.url}}{{site.baseurl}}/ml-commons-plugin/api/context-management-apis/)**：建立與管理對話脈絡的 API 參考文件。
