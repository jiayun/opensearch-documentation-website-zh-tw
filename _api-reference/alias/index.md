# 別名 API

OpenSearch 索引別名 API 可讓您建立、更新、刪除及擷取別名的相關資訊。

如需索引別名的概念性資訊（包括使用案例與範例），請參閱[索引別名]({{site.url}}{{site.baseurl}}/im-plugin/index-alias/)。

## 可用的 API

OpenSearch 支援下列索引別名 API。

| API | 說明 |
|-----|-------------|
| [管理別名]({{site.url}}{{site.baseurl}}/api-reference/alias/aliases-api/) | 新增或移除別名。 |
| [建立或更新別名]({{site.url}}{{site.baseurl}}/api-reference/alias/create-alias/) | 建立或更新別名。 |
| [取得索引別名]({{site.url}}{{site.baseurl}}/api-reference/alias/get-alias/) | 傳回一或多個別名的相關資訊。 |
| [刪除索引別名]({{site.url}}{{site.baseurl}}/api-reference/alias/delete-alias/) | 刪除現有的別名。 |
| [索引別名是否存在]({{site.url}}{{site.baseurl}}/api-reference/alias/alias-exists/) | 檢查別名是否存在。 |
| [CAT 別名]({{site.url}}{{site.baseurl}}/api-reference/cat/cat-aliases/) | 以表格格式列出別名，並包含路由與篩選資訊。 |
